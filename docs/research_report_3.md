# リサーチ（第3弾）：ストローの単価・業界・取引先の数

作成日: 2026-11-03 / 目的: 工場パートの卸値・おろし先・生産能力を現実に寄せるための材料

確度の表記は第2弾と同じです：✅一次情報や報道で確認済み / 🟡民間の数値・推計 / ❓未確認

## 1. ストローの単価
| 種類 | 1本あたり | 根拠 |
|---|---|---|
| プラスチック（透明・直径6mm×長さ210mm） | **約1.34円**（税込・2,500本入り） | 🟡 カウネット通販価格 |
| バイオマス配合（曲がる・500本入り） | 約2円 | 🟡 モノタロウ通販価格（税別998円） |
| 生分解性プラスチック | 3.4円 | 🟡 新潟大学の資料（10,000本入り1箱からの試算） |
| 紙ストロー | **3.9円** | 🟡 同上 |

- 紙ストローはプラスチックの**約3倍**。飲食店が紙ストローの導入をためらう理由として、使い心地とコストが挙がっている 🟡。
- 上の価格は通販（小売に近い）。メーカーの出荷価格（卸値）はこれより低い ❓。

## 2. 業界の構造
- 国内のストロー市場は**9割が輸入品**（韓国・中国）、国産は1割 ✅（報道）。
- 国産で最大手のシバセ工業（岡山県浅口市）は、**飲食店向け国産業務用ストローの約5割**を占める（同社調べ）✅。従業員は約37名、創業は大正15年 ✅（岡山県の資料）。
- 「ストロー発祥の地」とされる浅口市にもメーカーが多かったが、受注が減って**残りは4〜5社** ✅。
- 受注が減った理由：町の喫茶店が減り、チェーン店が増えた。シバセ工業は飲料用だけでなく工業用ストローにも販路を広げている ✅。
- 2022年4月に**プラスチック資源循環促進法**が施行。ストローは「特定プラスチック使用製品」（12品目）の1つで、提供する事業者には削減の取り組み（声かけ・有料化・代替素材への転換など）が求められる ✅。

## 3. 生産能力
- 紙ストローの製造機（ミヤコシ STO-001）は**最高で毎分150本**（直径6mm×長さ200mm）✅（メーカー資料）。
- プラスチックの押出成形ラインの速度（本/分）は見つからなかった ❓。
- ゲームは現在「約3秒で4.5本」＝**毎分約90本**。紙ストロー製造機の6割ほどで、小さな工場の最初のラインとしては現実の範囲。

## 4. 取引先（おろし先）の数
- 中小企業白書（2020年版）：製造業では**販売先が0〜10社**の企業が、「価格転嫁できなかった」と答える割合が最も高い。販売先が少ないほど値上げを通しにくい ✅。
- 東京都の調査（令和3年度）：外注先が**10社以下の企業が67.8%** ✅（販売先ではなく外注先の数値）。
- 販売先の数の平均と、上位1社に頼っている割合は確認できなかった ❓（e-Stat「中小企業実態基本調査」の表で調べられる）。
- 流通は「メーカー → 問屋・卸 → 飲食店」が中心と考えられるが、具体的な取引先は非公開 ❓。

## 5. ゲームへの提案（未実装・相談したい点）
1. **素材を分ける**：プラスチック（安い・規制で需要が減る）と紙（約3倍の値段・需要が増える）。品質強化の代わりに「紙ストローライン」を解放する形にできる。
2. **おろし先の種類**：喫茶店（少量・高値・減っていく）、チェーン店（大量・安値・値下げ交渉）、問屋（大量・中くらいの値段）、工業用（高値・高い品質が条件）。
3. **取引先の数と交渉力**：最初は3社。10社以下のうちは値上げ（品質強化の効果）が通りにくく、取引先を増やすと卸値が安定する。白書の「販売先が少ないほど価格転嫁しにくい」に対応。
4. **輸入品との競争**：ときどき「安い輸入品が入ってきた」イベントで卸値が一時的に下がる（国内の9割が輸入品）。
5. **規制イベント**：「プラスチック資源循環促進法」のように、プラスチックの需要が減って紙の需要が増える。

※ いまの卸値（1本12円）は、土地の値段（現実の1/2000）とのバランスで決めたゲーム内の値です。現実の1.3〜3.9円に合わせると、土地や機械の値段も一緒に調整する必要があります。
