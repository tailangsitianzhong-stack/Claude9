## 2. 株式（追加分）

### 2.1 売買のルール ✅
- 国内株の**売買単位は100株**（2018年10月に統一）。
- **呼値の単位**（注文できる値段の刻み）は銘柄の区分ごとに違う。例：株価1,000円以下の場合、TOPIX500構成銘柄は0.1円刻み、その他の銘柄は1円刻み。
- ❓ JPXのページに「2027年3月1日から現行の…」という記述の断片があったが、公式ページは取得できず（403）、内容は**未確認**。ゲームでは架空の刻み表を使えば問題ない。

### 2.2 モメンタムとリバーサル（学術的に繰り返し確認されている結果）🟡→学術
| 期間 | 起きやすいこと | 代表的な研究 |
|---|---|---|
| 1週間〜1か月 | **短期リバーサル**（上がった株が少し戻る） | Jegadeesh (1990) / Lehmann (1990) |
| 3〜12か月 | **モメンタム**（勝った株が勝ち続ける）。直近1か月を除いて測る「12-1」が定番 | Jegadeesh & Titman (1993) |
| 3〜5年 | **長期リバーサル**（行き過ぎた株が戻る） | De Bondt & Thaler (1985) |
- 解釈は割れている：投資家の「反応不足→過剰反応」で説明する行動ファイナンス派と、「リスクに見合った報酬」とするリスクプレミアム派。
- → ゲームでは**「トレンドが続く局面」と「行き過ぎが戻る局面」の両方**を入れると、読み合いが生まれる。

### 2.3 TOBプレミアムの実データ 🟡（民間の集計。基準ごとに分けて記載）
| 集計 | 基準株価 | 中央値・平均 |
|---|---|---|
| 2026年1〜9月・68件 | 発表前営業日の終値 | 中央値 **+27.9%**（60%以上も10件） |
| 2024年度 | 1か月の平均株価 | 中央値 **43.3%**（7.0〜275.1%） |
| M&A Online（2022年） | 3か月の平均 | 平均 約37% |
- → ゲームでは、プレミアムを**中央値30%前後・右に裾の長い分布**（たまに60%以上）で引くのが現実に近い。

### 2.4 企業価値（買収価格の根拠）
- **DCF法**：企業価値 = Σ(フリーキャッシュフロー ÷ (1+WACC)^t) + 継続価値（ターミナルバリュー）。そこから純有利子負債を引くと株主価値になる。
- **WACC** = 自己資本コスト×自己資本比率 + 負債コスト×(1−税率)×負債比率。
- **CAPM**：自己資本コスト = 無リスク金利 + β ×（市場リスクプレミアム）。
- WACCが1〜2ポイント変わるだけで評価額は大きく変わる → **金利が株価と地価の両方を動かす**、という第1弾の設計が裏付けられた。
- 借金（レバレッジ）を増やすと節税効果はあるが、株主のリスクが上がる。倒産コストとの釣り合いで最適な借入比率が決まる（トレードオフ理論。一般論で、今回は裏取りしていない）。→ ゲームでは「借金で工場を急拡大すると、金利上昇局面で倒産リスクが上がる」という仕組みにできる。

| ホテル | 東京 | 4.2% |

- → ゲームの初期値は「都心3%台前半、郊外の工業地4.5%前後、地方5〜6%台」が目安（地方の値は推定）。

### 3.2 工業地の地価の動向
- 令和8年（2026年）地価公示で、工業地の全国平均の変動率は**+4.9%**（前年+4.8%）🟡。新潟県の公表資料による数値で、国交省の資料本体では未確認。
- 東京都の工業地は13年連続で上昇、神奈川県は+6.0% ✅（各都県の発表）。
- 物流施設への需要（EC）を背景に、**工業地は住宅地より上昇が強い**時期が続いている。

### 3.3 大型工場が来たときの地価：TSMC熊本の事例 ✅（熊本日日新聞、熊本県の資料）
| 年（基準地価） | 起きたこと |
|---|---|
| 2022 | 菊陽町原水の工業地が **+31.6%**（全国1位） |
| 2023 | 菊陽町は8地点中6地点が+10%以上。隣の大津町も全用途で2桁の上昇 |
| 2024 | 大津町の商業地・工業地が全国トップ |
| 2025 | 県の平均は+1.7%。上昇は続くが伸びは縮小 |
| 2026 | 菊陽町は全用途で+4.8%に鈍化。アパートが建ちすぎて空室が目立つ |
- 地価は**急騰 → 周辺へ広がる → 供給が増えすぎて鈍化**という流れをたどった。
- → ゲームのイベント「大型工場の誘致」は、`中心区画 +30% → 翌年は隣接区画へ波及 → 3〜4年で効果が薄れる` とモデル化できる。

## 4. 工場の生産管理（ゲームの仕組み向け）
- **OEE（設備総合効率）** = 稼働率 × 性能（速度）稼働率 × 良品率。世界トップクラスは85%とよく言われる（🟡業界での通説）。→ 機械の「稼働率・速度・不良率」の3つをアップグレード項目にできる。
- **ボトルネック（制約理論、TOC）**：ライン全体の生産量は最も遅い工程で決まる。それ以外の機械の効率を上げても全体は増えない。→ 工場ゲームの核になるパズル。
- **タクトタイム** = 使える生産時間 ÷ 需要数。需要に合わせて生産ペースを決める考え方。
- **リトルの法則** = 仕掛品の量 = 処理量（スループット）× リードタイム。→ ベルト上の在庫の多さで滞留を目に見えるようにできる。
- 注意：OEEは機械単体の指標なので、待ち行列による滞留は反映されない → ゲームのUIでは「機械ごとのOEE」と「ライン全体の処理量」を分けて表示する。

## 5. ゲームバランスとWeb 3D実装

### 5.1 増分ゲームの数学（idle系・tycoon系ゲーム）🟡
- 次の購入コスト = 基本コスト × 成長率^所有数（例：AdVenture Capitalist の最初の施設は1.07、Cookie Clicker は1.15）。
- 1.07^10 ≈ 2倍、1.15^10 ≈ 4倍、1.15^50 ≈ 1,000倍以上。**コストは指数関数的に増え、収入は線形や多項式的にしか増えない**ので、自然に頭打ちになる。そこを倍率アップグレードや、転生（プレステージ）でリセットして解消する。
- 失敗例：初期の Cookie Clicker では、最上位の建物の生産量の伸びがコストの伸びを上回り、終盤のバランスが崩れた。
- → 提案：工場の増設は成長率1.10前後、土地は区画が限られているので価格は市場で決める。株は自分の買いで値が上がる（第1弾の平方根則）。3つとも違う仕組みで頭打ちになるようにする。

### 5.2 three.js の性能
- 重いのはポリゴン数より**描画命令（ドローコール）の数**であることが多い。まず `renderer.info` で測る。
- 同じ機械を約100台以上並べるなら **InstancedMesh**（ドローコールが n 回から1回になる）。形が違ってもマテリアルが同じなら **BatchedMesh**（r159以降）。
- ドローコールの目安：1フレーム100以下が理想、多くても500未満（🟡実務者の目安）。
- **Draco 圧縮**は glTF の容量を80〜90%減らすが、効くのはダウンロードだけで、描画の重さは変わらない。
- メッシュの結合は、かえって遅くなる場合がある（Babylon.js での報告）。変更の前後で必ず計測する。
