# ストロー工場タイクーン（開発中）

Web で遊ぶ 3D 経営ゲーム。小さなストロー工場から始めて、量産 → 資金 → 株・土地の買収 → さらに拡大、を目指す。
現在は **工場パート（スマホ縦画面）** の土台。

## 動かし方
```bash
npm install
npm run dev      # http://localhost:5173 （--host 付きなので同じ Wi-Fi のスマホからも開ける）
npm run build    # dist/ に静的ファイルを出力
npm run build:artifact  # artifact/index.html（1ファイル版、Claude の Artifact 公開用）
```

## いまできること
- 押出機 → 冷却槽 → カッター → ベルト → 結束機 → ベルト → 出荷倉庫 の生産ライン（約3秒で4〜5本の束）
- トラックが倉庫の束を積んでおろし先（3社・架空）へ配送。**おろした時点で利益が入る**
- 強化：生産スピード / トラック積載 / 品質（卸値）/ 倉庫の広さ（画面下）
- **舞台：栃木県鹿沼市**（特徴を取り入れた架空の配置。実際の地図の再現ではない）
  - 例幣使街道の杉並木、黒川、JR日光線と鹿沼駅（電車が走る）、東北自動車道と鹿沼IC、西の山並み、東の田んぼ
  - 瓦屋根の家・大谷石の塀と石蔵・庭のさつき（市の花）、産業団地の他社工場
  - 1本指ドラッグで移動、2本指でズーム・回転。画面下のボタンで工場・町全体へカメラ移動
- **工場の拡張（地面のボタンをタップ）**
  - 空き地：千渡・上殿町・府中町・西茂呂・鹿沼インター産業団地に「売地」。タップすると購入シートが開き、
    **1区画だけ買う / すべてまとめて買う（1割引き）** を選べる。本社の両隣も同じ仕組み
  - 値段 = 面積(336㎡/区画) × 参考地価(円/㎡) ÷ 2000 × 1.45^(持っている区画数-1)。
    参考地価は2026年公示地価の鹿沼市平均と町ごとの相場推計をもとにした値（`src/config.js` の `LOTS`）
  - 機械：買った区画に「押出機 → カッター → 結束機」の順でボタンが出る。3つそろうと新しいラインが稼働
- 倉庫が満杯になるとラインが止まる（ランプ：緑=稼働、黄=待機、赤=停止）
- 機械や作業員をタップすると説明を表示。ドラッグで回転、ピンチでズーム
- 自動セーブ（localStorage）。コンソールで `resetGame()` を実行するとリセット

## 構成
| ファイル | 役割 |
|---|---|
| `src/config.js` | バランス調整値・強化・従業員・おろし先 |
| `src/state.js` | お金・在庫・販売・セーブ（描画に依存しない） |
| `src/scene/models.js` | 機械の 3D モデル（プリミティブで作成） |
| `src/scene/town.js` | 鹿沼の町（家・道・川・線路・高速・田んぼ・山）。頂点カラーで1メッシュにまとめて軽量化 |
| `src/scene/factory.js` | 工場レイアウト・空き地の区画の座標 |
| `src/scene/buttons.js` | 地面に置く購入ボタン |
| `src/sim/plant.js` | 工場全体（建屋の伸縮・ライン・在庫の山） |
| `src/scene/setup.js` | レンダラー・カメラ・ライト |
| `src/sim/lane.js` | 1区画ぶんの生産ライン（シミュレーションとアニメーション） |
| `src/sim/truck.js` | 配送トラック |
| `src/sim/workers.js` | 作業員 |
| `src/ui/hud.js` | 縦画面 HUD |
